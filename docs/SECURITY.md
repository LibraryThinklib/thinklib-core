## Reporting a Vulnerability

If you have found a security vulnerability in Thinklib Core, **do not open a public issue**. This protects users of the project while a fix is being prepared.

Contact us directly at:

**thinktedlab@gmail.com**

Please include in your message:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We will do our best to respond within 7 days.
